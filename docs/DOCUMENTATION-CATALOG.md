# Complete documentation catalog

## Scope and authority

Every tracked Markdown document is listed once below, including this catalog. Categories describe purpose, not completion. Use the [source-of-truth map](SOURCE-OF-TRUTH.md) for topic owners, conflict resolution, missing specifications and evidence rules. Approved architecture parts remain current despite living in the reference directory; historical designs and old audits do not override them.

The catalog includes root onboarding, prototype instructions and the full docs tree: specifications, ADRs, delivery controls, preparation, weekly execution/acceptance/diagnosis, quality, security, clients, operations, learning, format, evidence, history and recovery maps. Non-Markdown manifests/contracts/source are implementation evidence located through their owning guides. Validation JSON/scripts/SQL are indexed by the [validation README](validation/README.md), not represented as Markdown documents.
