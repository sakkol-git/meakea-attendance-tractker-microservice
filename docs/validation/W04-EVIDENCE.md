## Accepted intent and current behavior

- ADR 010 and ADR 011 require token validation at the gateway and each Spring service via Spring Security OAuth2 Resource Server. `services/attendance` decodes RS256/JWKS tokens and protects all `/attendance/**` endpoints. Gateway routing for `/api/v1/attendance/**` strips prefix 2 and sanitizes caller headers, verified in `OrganizationGatewayRoutingIT`.
- Attendance migration V2 (`V2__attendance_core.sql`) adds PostgreSQL 18 tables: `attendance.command_receipt`, `attendance.attendance_evidence`, `attendance.attendance_session`, `attendance.attendance_outbox`, and `attendance.attendance_correction`. Raw GPS telemetry is stored in `attendance_evidence` with observed database constraint: uniqueness of `(tenant_id, client_observation_id)` preventing duplicate evidence (the database does not enforce GPS telemetry immutability). Work intervals in `attendance_session` enforce check constraint `clock_out >= clock_in` and partial unique index `attendance_session_one_open_idx` where `clock_out IS NULL`. Row Level Security (`FORCE ROW LEVEL SECURITY`) is enabled on all tables, isolating tenant data via PostgreSQL session variable `app.tenant_id`.
- MapStruct mapping policy (ADR 014) is implemented per explicit user decision: `AttendanceMapper` maps `AttendanceSession` to `AttendanceSessionResponse`, and `CorrectionMapper` maps `AttendanceCorrection` to `CorrectionResponse` using `@Mapper(componentModel = "spring")`.
- Idempotent `/attendance/check-in` and `/attendance/check-out` enforce `Idempotency-Key` header with payload SHA-256 hash receipt settlement. Replays return the canonical response without duplication; altered payloads with the same key return 409 Conflict. Check-in produces ETag `"0"` and appends `org.attendance.session.created.v1` to the transactional outbox. Check-out validates `If-Match` against entity version (stale revision returns 412 Precondition Failed), checks that an open session exists (attempting check-out before check-in returns 422 Unprocessable Entity), produces ETag `"1"` and appends `org.attendance.session.closed.v1` to the transactional outbox.
- Deterministic Flag Calculation (`AttendanceCalculationService`) is a plain status function implementing exact business invariants without speculative design patterns (ADR 013). Late flag applies strictly when `clockIn > shiftStart + graceMinutes`; at the exact grace boundary (`clockIn == shiftStart + graceMinutes`), status is deterministic and on-time (`late = false`). Early departure flag applies when `clockOut < shiftEnd`. Conflict review marks attendance recorded on a public holiday or during approved leave with `reviewRequired = true` and status `"REVIEW_REQUIRED"` with plain audit reason. `GET /attendance/today` returns `TodayAttendanceResponse` (`date`, `status`, and `sessions` list) matching both Web and Mobile client contract parsers. `GET /attendance/daily-status/me` and `/attendance/daily-status` expose the calculated status overview.
- Attendance Correction Lifecycle (`AttendanceCorrectionService` and `AttendanceCorrectionController`): requesting correction (`POST /attendance/corrections`) allows authenticated employees to submit proposed times and audit reasons while keeping raw evidence completely immutable. Independent approval (`POST /attendance/corrections/{id}/approve`) requires role `ROLE_MANAGER`, `ROLE_HR_ADMIN`, or `ROLE_TENANT_ADMIN`, strictly denies requester self-approval with 403 Forbidden, enforces `If-Match` concurrency, updates effective session times while preserving raw evidence links/timestamps, and produces outbox event `org.attendance.correction.approved.v1`. Rejection (`POST /attendance/corrections/{id}/reject`) denies requester self-decision (403), validates `If-Match`, sets status `REJECTED`, and produces outbox event `org.attendance.correction.rejected.v1`.
- Complete route tenant matrix (`AttendanceTenantMatrixIT`): all 10 attendance routes enforce authentication (401), reject missing tenant claim (403), enforce role restrictions (403), and prove complete cross-tenant boundary isolation.
