# Semantic releases

## Ten-minute concept

What: A version tag names an exact checked release with a changelog.

Why HRFlow needs it: Rollback needs known artifact/config/migration IDs, not latest.

## Tiny example

An initial v0.1.0 release records image digest and known limits before tag.

## Common mistake

> **Pitfall:** Moving a published version tag destroys traceability.
