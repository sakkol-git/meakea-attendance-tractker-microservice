# Weekly status template

## Position

Week and current step: record exact ID. Last green application tag: record actual tag or none. Gate result: **NOT RUN** until tests execute; then **PASS**, **CONDITIONAL PASS**, or **FAIL**.

## Evidence

- Demonstrated: one visible workflow and test report path.
- Failed: actual check, owner, recovery action and due date.
- Capacity: actual A/B hours, planned 70 percent, and time lost to setup/learning.
- Cut: explicit stretch removed; no critical tests removed.
- Deployment: release commit, host, smoke result, backup ID, scratch restore result.
- Pattern review: baseline pain, admission answers, value versus complexity, or rejection.
- Energy: rested, steady, tired, or stop; next week's adjustment.

## Handoff

Tomorrow's first action is one sentence naming a step or failing gate. Do not write “continue implementation.” A conditional pass cannot cover failed security/correctness/restore checks.
