# Definition of done

## Step

- [ ] One change takes 30 to 90 minutes, has a visible result, and has a focused commit.
- [ ] Any new term has a linked primer; at most two new concepts were introduced today.
- [ ] Expected result and failure recovery are checked; no secret is committed.

## Stone

- [ ] Required regression and negative tests pass with zero failures.
- [ ] Application startup and the stone's visible demonstration work.
- [ ] The final step's green tag points at the checked commit.
- [ ] A rejected pattern stays a simple method or switch; no quota-driven abstraction.

## Weekly gate

- [ ] Minimum Viable Gate evidence is recorded; Friday real-host redeploy and smoke pass.
- [ ] Backup exists on external media and a scratch restore was verified.
- [ ] Critical failures carry forward visibly; stretch is cut first.
- [ ] Thursday was buffer/review, weekend is rest, and next week's capacity is adjusted honestly.

## Release

- [ ] All Must checklist IDs have safe evidence, security and cross-tenant negatives included.
- [ ] Reboot, failed deploy, migration compatibility, secrets rotation and clean-host restore pass.
- [ ] HTTPS/auth/firewall/secrets/backup gate passed before external exposure.
- [ ] Known limitations and single-host outage risk are disclosed; guide completion is not product completion.
